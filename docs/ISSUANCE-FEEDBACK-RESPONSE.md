# 同稿签发、独立印发事实与一句话反馈

本轮接续 CEO-001/004 的全文标准 P0 具体岗位断点，以及反馈 P1 简洁性纠正；同一 PR #5，不合并或部署。不是全文国标通过声明。

## 已知事实按对应身份落位

正常填写稿的“红头、发文字号与签发人”内可填写已核签发人，正文末“印发机关与日期”保留独立印发事实。不要求选择文种或所有稿件补齐这些选填项，不生成签名、印章、审批事实。签发与落款独立；印发机关、印发日期分别填写，不从落款或成文日期借值。

半填印发信息及多行待核签发文字仍能保存、刷新恢复；生成前指出缺项/不支持输入并打开对应字段。旧预览会明确保留为旧结果，不能把它当当前稿导出。完整事实贯穿摘要、TXT、预览和实际Word/PDF。新非空元数据用v7保存稿；v1–6恢复缺省为空，正文/表格/附件/附注结构保持。空元数据不改变已有全篇判断身份；有事实变化时相关全篇判断重核。历史“复制新稿”清空独立日期，当前“复制后修订”保留当前事实，沿用原有区别。

引擎复用现有 signer/issuer/issueDate：仅新增的普通填写稿有签发且无红头时，将文号/签发段放到标题前；旧无签发和原有请示/报告次序不变。完整显式印发对即使无红头也生成文末版记；缺其中一项报明错误，函模板未支持该显式栏时如实说明。原Word保真路径未改。

独立审查发现并修复复合版头提醒错跳：检查器的Original是整段，不能凭包含签发人就跳签发字段，也不能凭date/reference规则名称猜来源。现在根据建议的最小改动范围定位实际字段；同名重叠、跨字段或无法确定时保守作为整篇核对。此修复未改变文档生成字节。

## 自然反馈与完整接收链

默认自然描述、截图说明、粘贴/拖图与选填联系方式，一次明确发送；独立岗位/目标/影响问卷及第二层发送确认均移除。普通版本/浏览器/系统信息在发送旁紧凑披露且可关闭，不附稿件、标题、URL、原始日志、屏幕尺寸或凭据。按需复杂材料仍可选，默认不选当前稿内容。

截图在真实点击的同一激活栈调用getDisplayMedia，仅视频无音频，浏览器仍需每次授权/来源选择；取消保留反馈文字。只取一帧，本地框选、遮盖与最终图片预览后发送；用完停止所有轨道，脱离video及监听，迟到授权也停止。确认后的遮盖已压平到最终PNG，重新编辑不会揭开原像素。此处不承诺免系统授权或所有浏览器均支持系统捕获。

接收前冻结payload和最终blob；发送中/结果未知不能清除或替换请求，相同私密ID重试。已收到后保留私密回执、补充、处理回复/状态/版本、附件删除和整条删除。处理列表改以自然说明摘要辨识，后台仅新增管理员已鉴权列表的100字符说明摘要，详情/分页/权限未扩。

三浏览器新简洁流程77项，捕获契约60项（合成授权流/帧，不是真实桌面来源选择），旧清除36项、证据51项、管理员摘要18项及迟到响应21项通过。真实正常writer至既有隔离PG完整链30项：请求已接收但响应中断→unknown→同ID去重，回执、回复、PNG补充、私有访问、删除及410防复活，当前稿精确不变。Go真实PG生命周期、相关单元与vet通过。测试后四内容表、有效请求及私有附件均0，必要删除墓碑保留。常规4173真实收集仍未启用，截图契约不能冒充系统选择器实测或正式运营验收。
