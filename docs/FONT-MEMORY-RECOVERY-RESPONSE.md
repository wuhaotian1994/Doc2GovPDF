## 改变与理由

- Go的sfnt解析器保留传入字节。原先先解析外来slice，再复制给PDF/Word字库，导致两份完整字体常驻；现在先取得一次owned副本，解析器与字体导出共用它。调用方随后修改原buffer不能改变已注册字形；相同已验证字节重复注册不再复制/解析，完整性只能升级。
- JS资源Map只去重进行中的读取，成功/失败后都释放Promise；可复用资源仍保存在经SHA验证的CacheStorage。字体逐面下载/编码/注册，减少两个完整面桥接缓冲重叠，已装字体不会因预览再下载。
- 网络/中断失败用中文明确提示排版资源未取得、填写未改变及重新生成预览。HTTP失败、内容哈希不匹配继续区分；不会以缩短正文或修改事实为恢复条件。
