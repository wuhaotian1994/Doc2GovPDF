## 当前行为

选中当前稿的完整段落后，原“插入表格”入口可直接组织现有文字。作者明确选择按列排格，或把已选字段作为表头、新建指定数量的待填行；随后查看二维预览与不进入表格的文字，再确认原位应用。没有选区时仍可插空表，并给出返回文稿选择已有文字的路径。

原文字、数字、空白及顺序保留。不足一整行和未选入表格的段落仍留在原位置，不跨过它们移动文字。原稿已有表、附件标识/标题及跨附件范围受到保护；不能精确定位的半段或容器边界明确拒绝。打开后稿件有变化时旧预览失效。正文和落款后文字共用现有历史，一次应用可一次撤销、重做，随后正常保存、重开、继续编辑和导出。

纯文字没有原始合并单元格、列宽和空格位置证据，因此这里是作者明确选择的新组织方式。不会声称恢复未知原表，也不会自动分配身份、人数、日期或其他事实。

顶部“复制后修订”直接复制当前填写稿或原 Word 工作稿。填写稿日期、文号、正文数字、表格和附注完整保留；原稿连同已有确认归档，新副本重新核对。历史列表“复制新稿”继续原有复用语义，不混淆两个用途。归档失败会阻止切换。

反馈面板默认关闭仍保留填写。低频“放弃未发送填写”经过就地确认后，清除本标签页未发送说明、选填信息、技术选择和本地证据副本；取消不清除。发送中或发送结果未知时拒绝该动作，已接收反馈及私密回执保持。不会发送服务器删除请求，也不修改文稿。
