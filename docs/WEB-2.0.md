# 2.0.0 Web 验收与交付

日期：2026-10-18。用户将产品改为纯网页版，明确废弃桌面视觉风格。本次实现为可独立托管的静态网页，不以 Wails 窗口、远程桌面或上传文档的服务冒充网页迁移。

## 产品与架构

现有 Go 文档模型、规则、修订、模板和 PDF 引擎保留；新增 internal/webengine 作为不依赖文件系统的边界，编译为 WebAssembly，在 Web Worker 内执行。导入的 File、PDF 与授权字体只在当前设备内存/IndexedDB 中流转。静态服务器仅响应 GET/HEAD；没有接收文稿的接口。没有分析统计、外部运行时 CDN 或在线字体请求。

新建、导入、编辑/撤销、七类模板、特殊要素、四级编号、表格/附件、逐项核对、批量整理、Word 修订/批注、成品 PDF 核对迁入浏览器。Word+PDF 一次打包下载 ZIP，避免浏览器多文件下载阻拦。正式导出检查在 Go/Wasm 边界再次执行；不能仅绕过按钮导出未确认的数字问题。

草稿及原件副本保存到 IndexedDB，页面隐藏时补保存；尚未保存时关闭页面触发浏览器保护。通过 Web Locks 保持同一站点只存在一个可编辑标签页，第二页明确提示并可在关闭前一页后重试。文件处理超时可终止 Worker，主界面和已保存草稿保留。静态缓存按全部资产摘要区分版本，新版不强制刷新正在编辑的旧页。

## 界面依据与检查

参考已确认的 [Squoosh](https://squoosh.app/) 和 [ImageOptim](https://imageoptim.com/mac)，采用直接接收文件、成品大画布与少量操作。界面源为 web/，旧 frontend/ 仅作桌面历史保留。新系统使用莓红操作、粉色接收区、温白背景、自托管中文界面字体和真实纸张预览；进入编辑仍为左正文、右成品。

已用 Impeccable Operate/new-work/craft-floor 与 UI/UX Pro Max 运行设计与核对流程。用户先前授权自主决定，且这次参考与替换意图明确，因此没有再要求用户选方案。概念脚本已运行，用户固定参考优先于随机方向。UI/UX Pro Max 的通用营销落地页建议与本任务不符，未采用其 Hero+Features 信息结构。

两轮后台桌面/手机截图检查：第一轮发现系统字体回退及预览过大；集中加入约 269 KB 的自托管中文界面字体，默认整页预览并保留适合宽度。第二轮确认 1440×960、390×844 下首页、编辑与表单无横向溢出。未继续无界面目标的打磨循环。

一次静态检测报告包含示例纸张缩略图 7–8px 字样、未完整列入 DESIGN.md 的状态色/半径，以及暖白配色提示。纸张字样是明确标记的文档缩略图，不承载控制标签；操作入口在图外明确命名。暖白与莓红是本轮选定视觉系统，未按通用检测器改回灰蓝。实际状态色保持文字解释和对比；不宣称检测器零发现。

## 实际测试

- `go test ./...`、`go vet ./...` 通过，包括新 Web 边界的损坏输入、无效编码与未确认数字导出拒绝。
- 真实无头 Edge 执行 18 项浏览器检查：引擎启动、手机布局、分栏实时 PDF、批量确认、实际 ZIP 下载、返回继续、IndexedDB 保存、七类模板/编号/附件、PDF 字体解析、损坏导入拒绝、7 份原稿导入导出、重载恢复、离线重载、浏览器前进后退、授权字体文件载入及无外部请求。
- 七份未编辑上游 Word 的下载字节与原件完全一致。七种模板 ZIP 内 Word/PDF 由独立 Python 解析核对标题、正文、附件和连续条号。
- 浏览器输出的 Word 由隐藏 Word 正常打开导出，再以 Poppler 与浏览器 Go PDF 并排检查：通知/报告/请示/函/纪要/非红头各 2+2 页，管理办法 3+3 页，共 30 个独立页面、15 张对照板，全部实际查看。没有正文丢失、文字遮挡、纸张越界或附件错序。
- 多标签保存保护另用两个真实浏览器标签验证，结果文件为 build/qa/web-storage-result.json。

所有过程通过无头浏览器、隐藏 Word、文件与进程工具完成，未操作用户鼠标键盘。使用真实文件和真实 Wasm 计算，非静态假数据截图或接口模拟。

## 明确边界

此轮验证环境为 Windows 11 上的 Edge；390px 手机视口为响应式模拟，没有声称已经在实体 iPhone/Android、Safari/Firefox 上验收。HTTPS 或 localhost 才能可靠使用离线缓存与草稿锁；直接 file:// 打开不支持。浏览器清除站点数据会删除本地草稿，建议成品及时下载。

浏览器不能扫描系统字体，因此默认输出使用内嵌 OFL 备用字体；指定公文字体可以由用户从授权文件导入。备用字体不代表指定字体合规。源 DOCX 保持原格式，复杂对象的 PDF 支持边界沿用 1.1.0，不声称复刻任意 Word 排版。

首次下载的 Wasm 约 37.7 MB，gzip 约 19.1 MB，之后可用离线缓存。UI 字体约 269 KB。桌面自动更新安装器由网页资产更新取代；旧桌面安装包保留，不再作为当前交付方式。当前仅在本机预览，没有对外公开部署。
