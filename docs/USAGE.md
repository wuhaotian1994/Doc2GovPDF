# 本地版使用说明

1. 运行安装包，确认安装到当前账户。安装完成后从开始菜单打开“公文整理”。
2. 已有材料选“导入文件”；只有文字选“粘贴正文”；从头起草选“新建公文”并填写标题、正文及必要要素。
3. 在成品预览中查看实际 PDF。点击“编辑正文”后，左边编辑、右边实时预览；停笔后自动更新，修改自动保存。表格可直接改格内文字，检查项在左侧“检查与修改”中展开；“完成编辑”收起左栏。“统一格式”可调整支持范围内的字体和版式。
4. 有问题时点击“定位原文”。确定写法修改可确认应用；需要判断的数字回到原文核对后编辑。可撤销。软件不会替你猜测正确数字。
5. 选择 Word、PDF 或 Word + PDF 后导出。文件名已存在时换一个名字；原文件保持不动。

如果提示公文字体缺失，严格要求指定字体的材料应先安装单位授权字体并重启软件；普通用途可勾选本次使用备用字体后导出。新建 Word 会嵌入所用的开源备用字体，PDF 同样使用该字体；原始导入 Word 保留自身字体设置。备用字体名称会明确显示，不能等同于指定公文字体。

草稿自动保存在本机。关闭前会等待保存；重新打开继续上次工作。设置中可填写常用单位信息、选择默认输出格式和清理本地草稿。清理草稿不删除已经导出的成品。

当前版本只保留本地，不连接更新发布服务。以后运行新安装包即可升级。卸载使用 Windows“已安装的应用”，原文件、导出成品和草稿保留。

软件可处理正文、简单表格及支持范围内的页眉页脚。带图片、公式或复杂对象的材料可能只能保留 Word，而无法生成 PDF；请按界面提示处理，不要把未检查的内容当作已通过。

编辑过程中，左上角“返回首页”可以随时回到初始界面。当前内容保留，首页“继续刚才的编辑”可接着处理。返回首页不会清空草稿；要换一份文件时，软件会在替换前提醒。

新建表单尚未点击“生成公文”，以及表格弹窗尚未点击“添加”时，内容也会自动保存在本机；正常关闭后重新打开可继续。取消添加表格会丢弃该表格草稿。已确认保留的问题在重新打开后仍保持确认状态。

添加段落/表格前可先点中插入位置；未选中正文时，新内容放在署名和版记之前。自己新建的段落和表格可删除，删除后可撤销。导入文件的原有结构继续受保护。
