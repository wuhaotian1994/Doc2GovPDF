# 开发记录

## 2026年10月14日

已建立产品需求和参考依据，完成第一阶段桌面流程：Go + Wails 原生窗口、本机正文处理、纯正文 DOCX/TXT 导入、基础非红头 DOCX 生成、日期与发文字号两类建议、逐项应用和撤销、自动草稿和恢复、DOCX 草稿导出。

基础版式按第一行标题、后续正文处理。Word 导入是明确的正文提取与重新排版；表格、图片、自动编号、页眉页脚、域和修订等结构会被拒绝，不宣称无损修复。正文数字和事实不自动修改。

已通过 Go 功能测试与静态检查。隔离的真实 Windows/WebView2 实例已验证 Go 绑定、两类规则命中、修改与撤销、直接导出动作、无效日期人工处理、文档 HTML 转义和草稿恢复。原生文件选择及另存对话框的完整人工操作、Word 实际渲染尚未验收。

测试钩子使用 `uitest` 构建标签，正式构建不包含测试脚本。初始构建大小约 9.7 MiB，不含共享 WebView2 Runtime。该数字仅反映当前开发预览，不能代表最终安装包体积。

Impeccable 已安装并应用，PRODUCT.md 与 DESIGN.md 已建立。已修复审查发现的对比度与样式偏差，补上键盘标签切换，并修复异步保存期间撤回内容可能被旧保存覆盖的问题。修正后布局截图和 11 项实际桌面交互检查通过。
