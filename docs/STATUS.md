# 本地版验收记录

初始验收日期：2026-10-14。最新版本：1.1.0 local（2026-10-17），各版本记录见下文。发布决定：用户要求暂不公开，仅交付本地安装包；未创建远程发布仓库，未上传源码、文档或安装包。

## 已实现

Go + Wails 桌面程序已完成导入、七类模板、正文/简单表格编辑、单位预设、格式统一、问题定位/修改/撤销、自动草稿、实际 PDF 预览、Word/PDF 导出、安装与卸载。独立检查报告已取消。

DOCX 解析保留源包；未修改文件按原字节输出。支持范围内的文字和格式变更写入修订，页眉编辑不重写正文；图片、公式、复杂域、既有批注和修订等按保护边界处理。不能可靠转换的内容明确阻止 PDF，不生成残缺成品。源文档始终不覆盖。

规则覆盖日期/发文字号、部分字体版式与体例、编号与枚举数量、异形词/文风、表格合计与比例、正文重复指标、跨表指标。机器不校验事实真实性，不猜改数值；模糊建议由用户确认。不是对任意 Word 排版的完全复刻，也不是完整标准认证。

## 明确边界

- Windows 10、4 核 8 GB 基准机、100%/150%/200% 的完整系统缩放矩阵、无 Office/无 WebView2 的干净虚拟机和 5 人可用性测试未执行。
- 系统原生选择/另存对话框通过 Wails 调用；自动桌面测试替代了对话框选择，实际文件写入另由后端测试验证，未声称人工逐项点击过所有对话框。
- DOCX 在第三方编辑器可能重新分页。1.1.0 的七类短/长样稿及扩展要素样稿，Word 与 Go PDF 页数均一致；导入原稿仍可能因字体及排版引擎产生不同换行。固定版式以实际 PDF 预览为准。
- 程序不支持任意复杂图文混排；嵌套表格、宏/嵌入文件等按输入边界拒绝，某些复杂对象仅保留 DOCX。正文到表格的任意语义对应未实现。
- 安装包约 243 MB（含约 214 MB 官方离线 WebView2）；自有 EXE 无商业代码签名。Microsoft 运行组件已验证有效签名。生产更新地址和密钥均为空，local 通道不启用联网更新。
- 未安装商业公文字体时使用有 OFL 分发许可的 Noto Serif SC 备用字体，需要用户确认；不把字体替代称为严格格式合规。

## 1.0.1：纠正默认非红头流程

用户指出交付结果不像红头公文后，复查发现 1.0.0 默认示例使用非红头文书，新建表单又把红头开关藏在折叠项中。此前“已完成”的表述没有充分区分功能可运行和正式版式验收，结论过早。

1.0.1 将新建通知/报告/请示等文种默认设为红头，直接展示红头选择和发文信息，发文单位必填；非红头文书可明确选择。首页示例改为有机关标志、文号、独立红色分隔线及版记的红头通知。修复没有填写文号时红线消失、红线和标题间距混用的问题。机关标志默认字号调整为 36 pt，过长时仍按现有规则缩小。

新增默认红头/切换非红头与导出包含机关标志及红线的桌面回归，当前共 14 项通过。未因此扩大到“任意文档严格符合国标”的承诺，专用字体缺失仍明确提示并要求确认替代。排版依据核对 [政府网站刊载的 GB/T 9704—2012 条文](https://www.ankang.gov.cn/WapContent-2060365.html)，并与项目固定版本的上游 letterhead.js 对照。字号和间距的结构修正不能替代不同字体下的精确着墨位置验收。

## 1.0.2：修复无法返回首页

工作区和新建表单增加明确的“返回首页”按钮；返回不清空内容，也不等待磁盘保存完成。首页提供“继续刚才的编辑”，可以回到原来的文档、编辑视图或未生成表单。新建其他文档前继续保护已有文档及已填写的表单；保存失败会保留错误提示和内存内容，不把用户困在工作区。

新增实际桌面回归覆盖示例返回/继续、首页取消替换、未保存编辑刷新到磁盘、保存失败时返回、表单保留及替换确认。与现有功能一起共 17 项检查通过。此次不改变公文排版和导出引擎。
