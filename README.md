# Doc2GovPDF

让小白用户能最简单的步骤完成公文生成与机检。

面向 Windows 的本地公文处理软件，计划使用 Go 重写 gongwen-kit 的核心能力，提供图形界面、DOCX 与 PDF 输出、可直接安装的 EXE 安装包和后台静默更新。

产品定位是围绕文件完成任务的公文整理与检查工具。用户导入文件或粘贴正文，软件排版、检查，再让用户确认必要问题并导出成品。主要交互参考 [Squoosh](https://squoosh.app/)。

当前阶段：产品需求分析。尚未实现应用、安装包或更新服务。
